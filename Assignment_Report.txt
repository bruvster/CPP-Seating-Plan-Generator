Formal CSP Problem Definition for the party seating problem:

    Variables : X1 to Xn tables where X is a table and n is the total number of tables
    Constraints: T1 to Tn where T is together pairs and n is number of together pairs
                 A1 to An where A is apart paires and n is number of apart pairs
    Domain : D1 to Dn where D is a table domain corresponding to the same numbered table
    States: One state is a seating arrangement that is consistent but can be incomplete or empty
    Complete Assignment: All of the guests have a seat (assumes none of the constraints have 
                         been violated)

Encoding format of a party seating problem and constraints:

Encoding and Maintenence of problem states:

    My program has a problem class that allows us to store the current remaining values, the
    constraints, the original guestlist, and the current arrangement (I call it arrangement
    to distinguish it from a final assignment). The heuristics are then taken care of during the
    value assignment phase of the RecursiveBacktracking function.

Search Strategies and Heuristics:

    My program utelizes the following heuristics:
    
    Minimum Remaining Values: While checking if a table has the current value in its domain, I 
    also check if the tables size is bigger than the others but not full. This means that the 
    table with the lowest number of empty seats will allways be assigned.
    
    Most Constraining Variable: The guestlist is preprocessed in search() ensuring that the
    values are ordered by most constraints to least constraints.

    Forward checking uses the constraints lists to make sure that upon a value assignment,
    the domains of the other tables are updated to make sure that no inconsistent assignments
    can be made. 
    Ex: Cathy is assigned to table 2, and has a constaint that she cannot sit next 
    to Bob, so Bob is removed from the domain of table 2.
    Ex2:Ken is assigned to table 4, and has a constraint that he must sit next to Andy, so Andy
    is removed from the domain of every table except table 4.
